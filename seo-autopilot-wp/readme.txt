== Description ==

**SEO Autopilot for WordPress** is a comprehensive SEO automation plugin that brings enterprise-level SEO tools directly into your WordPress admin dashboard.

= Key Features =

* **SEO Audit Engine** - Comprehensive scanning of posts, pages, and custom post types
* **AI-Powered Optimization** - Generate meta titles, descriptions, and content suggestions
* **Approval Workflow** - Review and approve AI changes before publishing
* **Backup & Rollback** - Automatic backups before publishing with easy rollback
* **Traveler Theme Support** - Specialized SEO for Traveler theme tours, hotels, and activities
* **Schema JSON-LD** - Automatic schema generation for articles, FAQs, local business, and more
* **Google Search Console** - Connect and sync GSC data for opportunity detection
* **Keyword Discovery** - Find and cluster keywords for better targeting
* **Reports** - Generate detailed SEO reports in HTML, PDF, or CSV
* **Automation** - Schedule weekly audits, GSC syncs, and content freshness scans

= Supported SEO Plugins =

* Yoast SEO
* Rank Math
* All in One SEO (AIOSEO)

= Traveler Theme Integration =

Full support for Traveler theme custom post types:
* Tours (st_tours)
* Activities (st_activity)
* Hotels (st_hotel)
* Rentals (st_rental)
* Cars (st_cars)
* Locations (st_location)

= Security First =

* Manual approval required before publishing AI changes
* Automatic backups before any content modification
* Encrypted API key storage
* Full capability-based access control
* Nonce verification on all actions

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/seo-autopilot-wp`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to SEO Autopilot > Settings to configure your AI provider
4. Run your first SEO audit from SEO Autopilot > SEO Audit

== Frequently Asked Questions ==

= Which AI providers are supported? =

We support OpenAI, Claude, Gemini, and OpenRouter. Configure your preferred provider in Settings.

= Does this work with my existing SEO plugin? =

Yes! SEO Autopilot works alongside Yoast SEO, Rank Math, and AIOSEO, enhancing them with AI-powered suggestions.

= Is my content safe? =

Absolutely. All AI changes require manual approval, and we create automatic backups before publishing any changes. You can rollback at any time.

= What is Traveler theme support? =

If you use the Traveler theme for tours, hotels, or activities, SEO Autopilot includes specialized optimization rules and schema generation for travel content.
